# 홈 연습실 이름·예약 현황 UI 변경 설계

## 목표

- 서비스 전체 연습실 이름을 `Pulse Lab 01`, `Pulse Lab 02`, `Pulse Lab 03`으로 통일한다.
- 홈 상세 카드 우측의 `오늘 사용 불가` 요약 박스를 제거한다.
- 원형 시간표 중앙을 숫자 요약 대신 `오늘` / `예약 현황` 두 줄 문구로 바꾼다.

## 변경 범위

### 연습실 이름

연습실 목록의 단일 원본인 `src/lib/reservations.ts`를 변경한다. 홈, 예약, 조회, 관리자 화면은 이 값을 그대로 사용하므로 별도 화면별 이름 덮어쓰기는 하지 않는다.

기존 예약 데이터의 `roomId`(`room-1`~`room-3`)는 유지한다. 표시 이름만 바뀌므로 저장 데이터와 예약 연결에는 영향이 없다.

### 홈 상세 카드

`src/app/page.tsx`에서 상세 카드 제목 옆의 사용 불가 시간 요약 박스를 삭제한다. 제목 영역은 남은 공간을 자연스럽게 쓰도록 단순화한다.

원형 중앙 패널은 아래 두 줄만 표시한다.

1. `오늘`
2. `예약 현황`

예약·점검 구간, 시간 눈금, 구간 라벨은 그대로 유지한다. 원형 그래프의 접근성 라벨은 특정 사용 불가 시간 합계 대신 오늘 예약 현황을 설명하도록 바꾼다.

## 테스트

- 연습실 원본 목록과 이름 조회 테스트를 새 이름으로 갱신한다.
- 홈 상세 카드의 표시 문구를 작은 뷰 모델 또는 문구 헬퍼로 검증해 `오늘 사용 불가` 요약과 중앙 숫자 문구가 다시 생기지 않게 한다.
- 전체 단위 테스트, 린트, 프로덕션 빌드를 실행한다.

## 제외

- 예약 가능 여부 계산
- 점검 구간 색상과 라벨
- 데이터베이스 스키마와 기존 예약 데이터
- 예약·조회·관리자 화면의 레이아웃
