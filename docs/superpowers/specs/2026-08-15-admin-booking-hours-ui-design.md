# 관리자 예약 시간 UI 축소 설계

## 목표

- 관리자 시간표와 점검 시간 선택에서 예약 운영시간인 `07:00~23:00`만 보여준다.
- 메인 원형 시간표는 하루 전체 `00:00~24:00` 표시를 유지한다.

## 화면 변경

- 관리자 시간표 행은 `07:00`부터 `22:30`까지 30분 단위로 표시한다.
- 점검 시작 시간은 `07:00~22:30`, 종료 시간은 `07:30~23:00`만 선택할 수 있게 한다.
- 공개 예약 화면과 V2 예약판의 기존 `07:00~23:00` 범위는 유지한다.
- 메인 원형 시간표의 48개 30분 슬롯은 유지한다.

## 구현 방식

공통 예약 시작·종료 상수인 `BOOKING_START_MINUTES`, `BOOKING_END_MINUTES`를 사용해 관리자용 표시 슬롯을 만든다. 하루 전체 상수와 `generateTimeSlots()`는 변경하지 않아 원형 시간표와 하루 전체 데이터를 다루는 로직에 영향을 주지 않는다.

서버 검증, 데이터베이스, 기존 예약과 점검 데이터는 변경하지 않는다. 운영시간 밖의 기존 데이터는 삭제하지 않지만 관리자 시간표 UI에는 표시되지 않는다.

## 테스트

- 관리자 시간표가 32개 행을 만들고 첫 행이 `07:00`, 마지막 행이 `22:30`인지 확인한다.
- 점검 시작·종료 선택지가 각각 운영시간 경계를 지키는지 확인한다.
- 메인 원형 시간표 데이터가 계속 48개 슬롯을 만드는 기존 테스트를 실행한다.

## 제외

- 원형 시간표 표시 범위 변경
- 예약 가능 시간 정책 변경
- 서버 검증 또는 데이터베이스 변경
- 기존 예약·점검 데이터 삭제
